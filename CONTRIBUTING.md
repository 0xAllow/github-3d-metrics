# Contributing

Open an issue to discuss substantial changes. Keep changes focused and include samples of rendered output for visualization changes. Use Node.js 24, install with `npm install`, and run the checks listed in the README. Use clearly labeled fixtures for tests. Keep access tokens out of commits, issue reports, screenshots, and logs.

Changes to metrics should specify the GitHub source field, aggregation, time window, and behavior for missing results. Update the corresponding tests and documentation with the change.
